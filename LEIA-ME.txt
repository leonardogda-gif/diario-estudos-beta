DIÁRIO DE ESTUDOS — v6.0

Esta versão parte da v5.28 corrigida para Leituras/Material e incorpora o Google Calendar.

LEITURAS
- Livro recebe data de início.
- A família pode alterar a data de início.
- Ao clicar “Concluir livro”, a data de conclusão é gravada.
- “Reabrir leitura” remove a conclusão.
- As datas ficam sincronizadas em family_books.

RELATÓRIOS
Novo filtro “Leituras”:
- Todos
- Registros de leitura
- Livros concluídos

A seção de livros concluídos mostra:
- título
- autor
- data de início
- data de conclusão

CALENDAR
Mantida a integração preparada na v5.29:
- importar um evento pessoal para o Planejamento;
- enviar um planejamento para o calendário secundário “Diário de Estudos”.

GOOGLE CLOUD
A Google Calendar API deve estar habilitada e o OAuth deve conter:
- calendar.events.readonly
- calendar.app.created
- calendar.calendarlist.readonly

BACKEND
- Worker v0.18-beta
- Não há nova migração D1.
